# SOKAR Visual Pack

[English](README.en.md) | [Español](README.md)

Planned images for the **SOKAR: La Venganza del Mal** project.

This directory is prepared to include the project's visual assets in original and web-optimized versions.

## Planned contents

### original-png/

PNG versions separated from the mockup or original artwork.

- `sokar-logo.png`
- `sokar-cover.png`
- `sokar-banner.png`
- `sokar-thumbnail-01-haunted-house.png`
- `sokar-thumbnail-02-sokar-entity.png`
- `sokar-thumbnail-03-flashlight-exploration.png`
- `sokar-thumbnail-04-stealth-mode.png`

### webp/

The same images converted to `.webp` for web usage.

- `sokar-logo.webp`
- `sokar-cover.webp`
- `sokar-banner.webp`
- `sokar-thumbnail-01-haunted-house.webp`
- `sokar-thumbnail-02-sokar-entity.webp`
- `sokar-thumbnail-03-flashlight-exploration.webp`
- `sokar-thumbnail-04-stealth-mode.webp`

### _source/

Original complete composite image, in PNG and WEBP.

- `sokar-generated-composite.png`
- `sokar-generated-composite.webp`

## Recommended usage

- `sokar-logo.webp` for project identity.
- `sokar-cover.webp` for Open Graph, cover and social sharing.
- `sokar-banner.webp` for the portfolio website.
- Thumbnails for cards, documentation, README files or technical previews.

## Note

The project is in concept/GDD phase, so images may come from concept art, covers, visual references or mockups until a playable demo exists.
